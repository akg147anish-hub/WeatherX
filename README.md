# 🌤️ WeatherX

A modern and responsive weather dashboard that provides real-time weather information for cities around the world using the OpenWeather API.

## 🚀 Live Demo

👉 https://weatherx-58xi.onrender.com

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature
- 🤗 Feels-like temperature
- 💧 Humidity information
- 💨 Wind speed
- 👁️ Visibility
- ☁️ Current weather condition
- 🌅 Sunrise and sunset time
- 📅 5-day weather forecast
- 📱 Responsive design for different screen sizes
- ⚠️ User-friendly error messages
- 🔐 API key protected using environment variables

## 🛠️ Tech Stack

- **Python**
- **Flask**
- **HTML5**
- **CSS3**
- **JavaScript**
- **OpenWeather API**
- **Render**

## 📸 Project Preview

The dashboard displays current weather conditions along with additional weather details and a 5-day forecast.
